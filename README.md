# Greens Shuttle React Website

React/Vite starter for rebuilding Greens Shuttle using the existing Greens Shuttle business information and a modern layout inspired by the supplied W Bundo reference.

## Run locally

```bash
npm install
npm run dev
```

## Current phase

- React + Vite
- Responsive navigation
- Home page
- Services page
- About page
- Gallery placeholder
- Contact page
- Booking form (frontend only)
- Reusable components and site data

## Next phase

Backend API, PostgreSQL database, authentication, booking management, email inbox/sending, attachments, document management and admin dashboard.
